# My First Website

## Project Description
This project is part of my GitHub Pages lab. It demonstrates how to create a basic website using HTML, manage files with Git, upload a project to GitHub, and publish a website using GitHub Pages.

## Technologies Used
- HTML
- Git
- GitHub
- GitHub Pages

## Purpose
The purpose of this project is to learn version control, repository management, and basic website deployment.

## Deployment
The website will be published using GitHub Pages once deployment is enabled in the repository settings.
